# Gemini Telegram Bot

Telegram-бот на Python, который подключается к Gemini API и позволяет общаться с нейросетью прямо в чате Telegram.

Бот умеет отвечать на обычные текстовые сообщения, работать с контекстом диалога, анализировать изображения и документы, а также генерировать картинки по текстовому описанию.

## Возможности

- общение с Gemini через Telegram-чат;
- сохранение контекста диалога для каждого пользователя;
- очистка истории командой `/clear`;
- генерация изображений по текстовому запросу;
- анализ фотографий;
- анализ документов;
- использование Google Search в ответах Gemini;
- логирование запросов, ответов и времени обработки.

## Команды бота

### `/start`

Запускает бота и создаёт новый диалог с Gemini для пользователя.

### `/clear`

Очищает контекст текущего диалога и начинает новую сессию общения.

## Как работает бот

После запуска бот начинает слушать входящие сообщения в Telegram.

Если пользователь отправляет обычный текст, сообщение передаётся в Gemini, а ответ возвращается обратно в чат.

Если в сообщении есть слова вроде `нарисуй`, `сгенерируй`, `draw`, `изобрази` или `картинка`, бот запускает генерацию изображения и отправляет готовый результат пользователю.

Также бот умеет принимать фотографии и документы. Файл временно сохраняется, загружается в Gemini API, после чего модель возвращает ответ по содержимому файла.

## Установка и запуск

Клонировать репозиторий:

```bash
git clone https://github.com/shushablinchik/internship.git
cd repository-name
```

Создать виртуальное окружение:

```bash
python -m venv venv
```

Активировать окружение:

Windows:

```bash
venv\Scripts\activate
```

macOS / Linux:

```bash
source venv/bin/activate
```

Установить зависимости:

```bash
pip install aiogram google-genai
```

Запустить бота:

```bash
python gemini.py
```

## Настройка

Для работы нужны два ключа:

- токен Telegram-бота из BotFather;
- API-ключ Gemini.

Они используются в файле `gemini.py` в переменных:

```python
TELEGRAM_TOKEN = "..."
GEMINI_API_KEY = "..."
```
