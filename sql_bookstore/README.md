# SQL-анализ продаж книжного магазина

В этом проекте собрана небольшая база книжного магазина и несколько запросов для анализа продаж.

## Файлы

- `schema.sql` — создание таблиц и тестовые данные
- `analysis_queries.sql` — запросы для анализа

## Что можно посмотреть

- выручку по месяцам
- самые продаваемые книги
- средний чек по клиентам
- клиентов с повторными заказами
- долю выручки по жанрам

## Как запустить

Пример для SQLite:

```bash
sqlite3 bookstore.db < schema.sql
sqlite3 bookstore.db < analysis_queries.sql
```
